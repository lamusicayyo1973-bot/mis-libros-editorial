# 📚 SISTEMA EDITORIAL REUTILIZABLE: DE MANUSCRITO A VENTA

Este sistema está diseñado para repetir el proceso de publicación y venta de tus eBooks en **Gumroad**, **Hotmart**, **Amazon KDP** y tu **propia Landing Page**, de forma estructurada y en pocos minutos para cada nuevo libro.

---

## 🔑 DATOS QUE NECESITAS TENER A MANO PARA CONFIGURAR LOS COBROS

Por razones de seguridad bancaria, las plataformas exigen que tú mismo conectes tus datos de cobro. Esto es lo único que debes ingresar una sola vez en cada plataforma:

### 1. En Gumroad (El más fácil)
* **Email de PayPal** (para recibir pagos instantáneos) **O**
* **Datos bancarios locales:** Nombre completo del titular, País, IBAN/Número de cuenta.
* *Frecuencia de cobro:* Pago automático cada viernes.

### 2. En Hotmart (El más usado en Latam)
* **Documento de Identidad:** Foto de DNI, Pasaporte o RUT (para verificar identidad).
* **Cuenta bancaria personal:** Nombre de titular, CBU/IBAN/SWIFT o cuenta local.
* *Frecuencia de cobro:* Puedes retirar a tu banco cuando quieras a partir de 2$ USD acumulados.

### 3. En Amazon KDP (Para vender en tienda Kindle)
* **Cuenta bancaria:** Código de ruta y número de cuenta (o IBAN).
* **Entrevista Fiscal (Tax Interview):** Un formulario de 2 minutos dentro de la web donde ingresas tu DNI/RUT/CUIT para no retener impuestos dobles en EE.UU.

## 🛠️ ESTRUCTURA DEL PROCESO PARA CADA NUEVO LIBRO

Para cada libro futuro, solo debes seguir esta checklist de 4 pasos:

### PASO 1: Preparar la Carpeta del Libro
Crear una subcarpeta en `sistema_editorial/libros/nombre-del-libro/` con:
1. `libro.pdf` (El archivo final del libro).
2. `portada.jpg` (La portada en alta resolución).
3. `ficha_producto.json` (Los datos del libro: título, precio, descripción, puntos clave).

### PASO 2: Generar la Página de Ventas (Landing Page)
Usar la plantilla HTML reutilizable que incluimos en el sistema para tener una web de ventas en 1 minuto.

### PASO 3: Subir a Plataformas (Proceso Express)
Como la ficha del producto ya tiene todo el texto redactado y optimizado:
* **Copiar y pegar** el Título, Subtítulo y Descripción.
* **Adjuntar** el PDF y la Portada.
* **Fijar** el precio ($20 USD).
* **Obtener** el link de compra.

### PASO 4: Lanzamiento y Promoción
Vincular el botón de compra de tu Landing Page al link de Gumroad/Hotmart y compartirlo en redes sociales.
